# Security policy

## Supported versions

Only the latest minor version receives security fixes.

| Version | Supported |
|---------|-----------|
| 0.3.x   | ✅        |
| < 0.3   | ❌        |

## Reporting a vulnerability

Please **do not open a public issue** for a vulnerability.

Write to **cdelage.dev@gmail.com** with the subject "Security", in English or French:
the affected version, the configuration, the steps to reproduce, and what an attacker
gains. You will get an answer within 72 hours. Once a fix is released, a GitHub
security advisory is published with credit to you, unless you prefer otherwise.

The full disclosure policy (timelines, safe harbour, scope):
<https://mirelabs.fr/en/responsible-disclosure>.
